# Sami WireGuard Store

نسخه اولیه یک فروشگاه گیمری WireGuard با پنل مدیریت است.

## اجرا
1. Node.js 20+ نصب باشد.
2. `npm install`
3. `.env.example` را به `.env` تغییر نام بده و ADMIN_USER / ADMIN_PASSWORD / JWT_SECRET را عوض کن.
4. `npm start`
5. مرورگر: `http://localhost:3000`
6. پنل: `http://localhost:3000/admin.html`

## امکانات فعلی
- فروشگاه گیمری Responsive
- افزودن/حذف/فعال‌سازی محصول از پنل
- ثبت سفارش و آپلود رسید
- مشاهده رسید در پنل
- تأیید/رد پرداخت
- ثبت کانفیگ WireGuard برای سفارش
- ثبت وضعیت تحویل
- تنظیم نام فروشگاه، کارت، آیدی پشتیبانی، ربات، کانال و Bot Token
- داشبورد آماری

## اتصال واقعی تلگرام
ساختار آماده است، اما ارسال پیام/وبهوک Telegram باید با Bot API و webhook امن تکمیل شود. توکن را در `.env` یا Secrets هاست نگهداری کن، نه در کد یا فرانت‌اند.

## ایده‌های مرحله بعد
- ورود مشتری با Telegram Login
- لینک یک‌بارمصرف تحویل
- موجودی کانفیگ‌های WireGuard و تخصیص خودکار
- انقضای سرویس و حجم مصرفی
- اعلان خودکار تلگرام
- کد تخفیف
- درگاه پرداخت آنلاین
- آمار فروش و گزارش CSV
- بکاپ دیتابیس
